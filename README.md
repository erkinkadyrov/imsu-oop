# IMSU OOP

My solutions for the Object Oriented Programming course. Each assignment is in
its own folder.

- `assignment1` - Python review, around 40 small tasks
- `assignment2` - a single class (Student)
- `assignment3` - personal account (Amount + PersonalAccount)
- `assignment4` - User, UserService, UserUtil
- `assignment5` - device shopping cart with inheritance

Only standard Python 3 is used, no extra libraries.

Run any assignment:

```bash
cd assignment1
python3 main.py
```

For assignments 3, 4 and 5 there are tests:

```bash
python3 -m unittest -v
```
