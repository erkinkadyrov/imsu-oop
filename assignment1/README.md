# Assignment 1 - Python review

About 40 small tasks, split into files by topic:

- arithmetic.py - tasks 1-5
- conditions.py - tasks 6-10
- for_loops.py - tasks 11-15
- while_loops.py - tasks 16-20
- functions.py - tasks 21-25
- arrays.py - tasks 26-35
- strings.py - tasks 36-40

Each file can be run directly, for example:

```bash
python3 arithmetic.py
python3 strings.py
```

Every task is written as a separate function, so they can also be imported, e.g.
`hypotenuse(3, 4)` returns `5.0`, `gcd(56, 98)` returns `14`,
`to_binary(13)` returns `"1101"`.
